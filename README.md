# 🎙️ Voice Assistant

## Description
A simple Python voice assistant that listens to user voice commands and responds using speech.

## Features
- Voice input recognition
- Text-to-speech response
- Basic command handling

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3

## How to Run
pip install speechrecognition pyttsx3 pyaudio
python voice_assistant.py

## Learning Outcome
- Speech recognition
- Python libraries usage
- Audio processing basics
