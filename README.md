\# 🎙️ Amigo – Python Voice Assistant



\## 📌 Description



Amigo is a simple Python-based voice assistant that listens to voice commands, recognizes speech, and responds using text-to-speech. It can perform basic tasks such as opening websites, searching for information, and providing the current date and time.



\## ✨ Features



\- 🎤 Voice input and speech recognition

\- 🔊 Text-to-speech responses

\- 🌐 Open websites using voice commands

\- 🔎 Search for information using Wikipedia

\- 🕒 Get the current date and time

\- 💬 Basic voice command handling

\- 👋 Exit the assistant using a voice command



\## 🛠️ Technologies Used



\- Python

\- SpeechRecognition

\- pyttsx3

\- PyAudio

\- Wikipedia

\- Webbrowser

\- Datetime



\## 💻 Requirements



\- Python 3 installed on your computer

\- A working microphone

\- Internet connection for online speech recognition and Wikipedia searches



\## 🚀 How to Run



\### Step 1: Clone the Repository



```bash

git clone https://github.com/pinjarireshma7890/voice-Assistant.git

```



\### Step 2: Open the Project Folder



```bash

cd voice-Assistant

```



\### Step 3: Install Required Libraries



```bash

pip install SpeechRecognition pyttsx3 PyAudio wikipedia

```



If PyAudio installation fails, check the installation instructions for your Python version and operating system.



\### Step 4: Run the Voice Assistant



Make sure the Python filename is `voice\_assistant.py`, then run:



```bash

python voice\_assistant.py

```
