# 🎙️ Amigo – Python Voice Assistant

## 📌 About the Project

Amigo is a simple Python-based voice assistant that listens to voice commands through a microphone and responds with speech. It can perform basic tasks such as opening websites, providing the current date and time, and searching for information.

This project was developed as a Python learning project to understand speech recognition, voice responses, and basic automation.

## ✨ Features

- 🎤 Voice command recognition through a microphone
- 🔊 Spoken responses using Windows text-to-speech
- 🌐 Open websites such as Google, YouTube, and Gmail
- 🔎 Search for information using Wikipedia
- 🕒 Tell the current time and date
- 📝 Open Notepad and Calculator
- 👋 Exit the assistant using a voice command

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Wikipedia
- Webbrowser
- Datetime
- Windows PowerShell Speech Synthesis

## 💻 Requirements

- Python 3
- Windows operating system
- Working microphone
- Internet connection for online speech recognition and Wikipedia searches
- Required Python libraries

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/pinjarireshma7890/voice-Assistant.git
```

### 2. Open the Project Folder

```bash
cd voice-Assistant
```

### 3. Install Required Libraries

```bash
pip install SpeechRecognition PyAudio wikipedia
```

### 4. Run Amigo

```bash
python amigo.py
```

Allow microphone access if Windows requests permission.
